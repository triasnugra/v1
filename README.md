Situs asgracrypto sudah jadi, dengan desain dan mesin aturan baru. Halaman lama tidak tersentuh, jadi bisa kamu bandingkan. Sudah kuuji dengan data Binance tiruan (halaman jalan sampai selesai, 300 uji acak tanpa error), tapi belum dengan data Binance sungguhan.

Pasang: taruh dua file, index.html dan engine.mjs, di satu folder (misalnya asgracrypto/). Buka lewat alamat GitHub Pages, bukan klik dua kali file HTML-nya. Tidak perlu GitHub Actions atau API key.

Tampilan: tema Google (putih dengan biru, merah, kuning, dan hijau), logo teks berwarna, dan kotak pencarian bulat. Ketik BTC atau SOL lalu Enter untuk menganalisis koin apa pun di Binance. Mode gelap otomatis mengikuti perangkat.

Isinya:

Ringkasan: Gerbang BTC (range 4H, Monday Range, struktur harian), dominasi BTC dan musim altcoin, serta 3 setup terkuat. Alert bahasanya sudah dikoreksi: BTC di tengah range berarti “diam di BTC, cari altcoin”.
Setup: kartu dengan entry limit di retest, SL, target bertahap (garis tengah, tepi range, box HTF), rasio R, status konfirmasi 4H/12H, dan kalkulator ukuran posisi.
Pantauan: 40 koin dengan posisi di range, pola, dan status.
Detail koin (ketuk koin): grafik 4H atau 1D dengan kotak demand/supply, garis tengah, Monday Range, trendline Wolf, entry, SL, TP. Di bawahnya ada rencana jika-maka seperti gaya Eliz.
Strategi: aturan yang dipakai, diberi label Dari Eliz atau Tafsiran.

Yang berbeda dari versi lama: tidak ada filter EMA atau OBV sama sekali. Arah dibaca dari struktur harga (naik, turun, atau datar), dan level berupa kotak di tepi range taktis 4H plus range swing 1D. Pola yang dikodekan: sweep dan reclaim, Double Deviation, Three Tap/Top, Wolf, breakout dengan acceptance, failed reclaim, dan sweep Monday Low/High.

Yang perlu kamu ketahui:

Angka seperti range 21 hari (4H), 120 hari (1D), tebal kotak 0,5 ATR, dan definisi acceptance (2 close) adalah tafsiranku, bukan angka Eliz.
Sweep Monday cukup sering muncul pada uji acak. Kalau di data nyata terlalu ramai, ambangnya bisa diperketat.
Belum ada jurnal otomatis dan backtest, dan tanggal FOMC harus kamu verifikasi di federalreserve.gov. Dua hal itu bisa kita tambahkan berikutnya.
Ini alat bantu riset, bukan jaminan hasil. Uji dulu tanpa uang sungguhan.
